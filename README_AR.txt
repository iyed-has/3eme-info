Fasl | 3ème Info — نسخة عمل لربط مكالمات LiveKit

الملفات: index.html واجهة الموقع، fasl-config.js إعدادات الواجهة، api/livekit-token.js إصدار رمز الاتصال على الخادم، supabase_setup.sql مخطط قاعدة البيانات، package.json وvercel.json للنشر.

LiveKit: عنوان المشروع مضبوط من الصورة. مفتاح API والسر لا يوضعان داخل HTML؛ أضف LIVEKIT_API_KEY وLIVEKIT_API_SECRET في Vercel > Settings > Environment Variables ثم أعد النشر.

Supabase: تم إدخال Project URL والمفتاح العام اللذين أرسلتهما في fasl-config.js. ملاحظة: إعدادات الاتصال موجودة، لكن تسجيل الدخول والشات لا يزالان بحاجة إلى ربط فعلي بقاعدة Supabase؛ الواجهة الأصلية تستخدم localStorage لهذين الجزأين. هذه النسخة لم تربط بعد تسجيل الدخول والشات بقاعدة Supabase؛ الواجهة الأصلية ما زالت تستخدم localStorage لهذين الجزأين.

المكالمة: أضفت عميل LiveKit، طلب الرمز من /api/livekit-token، الاتصال بالغرفة ونشر الصوت/الفيديو ومشاركة الشاشة إلى المشاركين عند توفر إعدادات Vercel وصلاحيات المتصفح. اختبر بعد النشر عبر HTTPS.

كود الأستاذ ما زال كما في الملف الأصلي لأجل تجربة الواجهة فقط؛ لا تعتمد عليه كحماية حسابات حقيقية قبل نقل التحقق إلى الخادم.
